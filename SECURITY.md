# Security / Безопасность

This repository hosts reverse-engineering artifacts for research purposes. Treat extracted binary sections and recovered code as untrusted. Do not execute unknown material on your personal computer. Analyze it only in a controlled environment.

If you find credentials, tokens, personal data, or other secrets in the archive, **do not publish or amplify them**. Report the exact file and location privately to the repository owner through their GitHub profile. Do not include the sensitive value in a public issue.

---

Репозиторий содержит материалы реверс-инжиниринга. Не запускайте неизвестные файлы на основной системе. Если найдёте токены, пароли или персональные данные, не публикуйте их; сообщите владельцу репозитория приватно.
